\## Слайд 3: UML компонентов и последовательности



\*\*Компоненты:\*\*

\- Модуль А (Каталог) - порт 5001 - Python/Flask

\- Модуль Б (Корзина) - порт 5002 - Python/Flask

\- Модуль В (Сделки) - порт 3000 - Node.js

\- Модуль D (Задачи) - порт 5003 - FastAPI

\- Модуль E (Отчеты) - порт 3001 - Python/Flask



\*\*Последовательность оформления заказа:\*\*

1\. UI → Модуль Б: POST /cart/add

2\. UI → Модуль В: POST /deals/create

3\. UI → Модуль D: POST /tasks/create

4\. UI → Модуль Б: POST /cart/clear

5\. UI → Модуль E: POST /reports/sales

\## Слайд 4: Архитектура интеграции + CI/CD



\*\*Архитектура:\*\*

\- Микросервисная архитектура (5 сервисов)

\- Синхронное взаимодействие через HTTP/REST

\- JSON формат данных

\- CORS настроен для всех модулей



\*\*CI/CD (GitHub Actions):\*\*

\- Автоматический запуск при push

\- Проверка синтаксиса

\- Запуск unit-тестов

\- Сборка Docker образов



\*\*Docker:\*\*

\- docker-compose.yml для оркестрации

\- PostgreSQL для данных

\- Redis для кэша
