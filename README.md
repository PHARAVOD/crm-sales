

\## 🚀 Быстрый старт



\### Предварительные требования



\- Docker Desktop 20.10+

\- .NET 10.0 SDK (для интеграционных тестов)

\- Node.js 18+ (для модуля В)

\- Python 3.11+ (для модулей А, Б, D, E)



\### Запуск через Docker Compose



```bash

\# Клонировать репозиторий

git clone https://github.com/your-username/integration-practice.git

cd integration-practice



\# Запустить все сервисы

docker-compose up -d --build



\# Проверить статус

docker-compose ps
