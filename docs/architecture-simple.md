\# Архитектура CRM системы (простыми словами)



\## Что это за система?



Это интернет-магазин с CRM для отдела продаж. Покупатели могут:

\- Смотреть товары

\- Добавлять в корзину

\- Оформлять заказы



Менеджеры могут:

\- Смотреть лидов и сделки

\- Управлять задачами

\- Смотреть отчеты

\## Какие технологии используются?



| Сервис | Язык/Фреймворк | Что делает |

|--------|----------------|-------------|

| А | Python/Flask | Товары и лиды |

| Б | Python/Flask | Корзина |

| В | Node.js/Express | Сделки |

| D | Python/FastAPI | Задачи |

| E | Python/Flask | Отчеты |

| База | PostgreSQL | Хранит данные |

| Кэш | Redis | Ускоряет загрузку |



\## Как сервисы общаются друг с другом?



\- Через HTTP запросы (REST API)

\- Сайт → Сервис А → получает товары

\- Сайт → Сервис Б → добавляет в корзину

\- Сайт → Сервис В → создает заказ



\## Что такое Saga Pattern (для отчета)?



Это способ отмены действий если что-то пошло не так.



Пример:

1\. Списали деньги → ОК

2\. Проверили остатки → ОШИБКА (товара нет)

3\. Запускается компенсация → деньги возвращаются
